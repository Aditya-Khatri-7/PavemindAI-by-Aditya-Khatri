4. SYSTEM COMPONENT SPECS

A. Geometric Size Estimation
Physical dimensions are calculated using flat-ground perspective geometry:
- Camera Height (H)   : 1.3 meters (configurable)
- Focal Length (f)    : 800 pixels (configurable)
- Tilt Angle (theta)  : 18.0 degrees down (configurable)
Distance is computed as D = H / tan(theta + phi_y), and physical width is
derived as W = (w_px * D) / f.

B. Multi-Factor Severity Scoring
Severity is evaluated using a weighted image-space scoring formula:
  Score = 0.60 * Size_Factor + 0.20 * Confidence_Factor + 0.20 * Aspect_Factor
- Minor    : Score < 0.40
- Moderate : 0.40 <= Score < 0.70
- Severe   : Score >= 0.70
